About the course

No-code AI tools for responsible task automation.

The GRAPH Courses · 8-week live cohort


Generative AI for Work & Research Productivity

This course combines weekly live workshops, help sessions, community discussion, assessment feedback, capstone coaching, and a tutorial library. The goal is practical: use AI responsibly to create documents, analyze data, synthesize research, build chatbots, automate workflows, and communicate findings clearly.


  • Responsible AI use for academic and professional tasks
  • Hands-on workflows using no-code and low-code AI tools
  • Capstone project and showcase for applied learning
Module 1

Websites, Documents & Presentations

LLMs, Markdown, LaTeX, HTML, project websites, and research communication assets.

Module 2

AI-Automated Data Analysis

Code Interpreter, Julius, dashboards, data transformations, reports, and visualizations.

Module 3

Research & Text Analysis

Literature review, classification, sentiment, knowledge maps, and synthesis systems.

Module 4

Custom GPTs & Chatbots

RAG systems, custom assistants, Botpress workflows, and knowledge-base integration.

Module 5

AI for Task Automation

Agents, browser control, app-to-app workflows, and practical automation design.

Module 6

Communication & Outreach

Research summaries, scientific figures, video abstracts, visualization prompts, and scheduling.

Module 7

Capstone Project & Showcase

Peer feedback, final presentations, public Q&A, and responsible AI practice.
